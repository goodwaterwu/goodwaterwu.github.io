Firmware工程師聚焦版 (Google/Amazon/Meta)

📋 計劃總覽

目標： 在兩個月內系統性地完成LeetCode最核心的150題中的基礎和中等難度題目。

側重點：： 陣列(Array)、字串(String)、鏈表(Linked List)、樹(Tree)、排序(Sorting) 和 二分搜尋(Binary Search)。這些是韌體(Firmware)面試中最常出現的題型。

公司偏好：： 優先選擇在Google、Amazon (AWS)、Meta (Facebook)的面試中出現頻率较高的題目。G Google A Amazon M Meta

題型標記：： Array String LL Tree Sort BS 2P Stack DP HT

難度控制：： 排除“Hard”難度的題目，專注於建立堅實的基礎。

節奏：： 每週工作5天，每天3-4題，週末休息和消化吸收。

總結與建議

持續練習：： 刷題是一個長期過程，即使完成150題，也要保持每天練習的習慣。

理解而非記憶：： 確保理解每道題目的解題思路、時間複雜度和空間複雜度，而不是死記硬背。

多語言實現：： 嘗試用C/C++實現，因為韌體工程師面試通常會要求C/C++。

模擬面試：： 在後期可以嘗試進行模擬面試，提高臨場應變能力。

擴展學習：： 如果時間允許，可以進一步學習Trie、Segment Tree、Fenwick Tree等進階資料結構，以及更複雜的圖算法（如Dijkstra、Floyd-Warshall）。
